# Очередь AI SEO на Amvera

Основной сценарий не требует cron: после публикации Next.js запускает обработку через
`after` в том же Node-процессе. Очередь в PostgreSQL остаётся на случай перезапуска,
таймаута модели или временного сбоя сети.

Для страховки создайте в панели Amvera отдельный **Cron Job**, который вызывает:

```text
GET https://aliceinrussialand.ru/api/cron/seo
Authorization: Bearer <CRON_SECRET>
```

Расписание Amvera использует UTC и Quartz-синтаксис. Рекомендуемое расписание — раз в
10 минут:

```text
0 0/10 * * * ?
```

Укажите максимальное время работы 60 секунд и политику запуска `FORBID` (не начинать
второй запуск, пока предыдущий не завершён). `CRON_SECRET` должен совпадать с секретом
одноимённой переменной основного приложения; его не помещают в URL, код или Git.

Если отдельный Cron Job пока не создан, автоматизация всё равно срабатывает сразу после
публикации. Cron нужен только для повторных попыток и задач, которые не успели
выполниться до перезапуска процесса.
