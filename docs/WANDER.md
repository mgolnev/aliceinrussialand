# «Не выбирай»

Вход над главной лентой ведёт на `/wander`. Страница показывает одну иллюстрацию
из опубликованной подборки. Изображение открывает исходную публикацию, «вся
подборка» — её обычную страницу. «Выйти к ленте» доступно постоянно.

## Переходы

1. Первая подборка выбирается случайно, без перевеса в пользу больших серий.
2. Если текущая работа состоит в другой подборке с непросмотренными работами,
   следующий шаг проходит через эту связь.
3. Внутри подборки предпочтение получают только настоящие переходы: после
   работы-пересечения в соседней подборке должна оставаться другая работа.
4. Без явной связи показывается не больше двух работ одной серии подряд, пока
   доступны другие серии. После ухода маршрут по возможности возвращает
   начальный мотив другой работой.
5. Публикация не повторяется в пределах маршрута, даже если посетитель вернулся
   к более ранней работе. По исчерпании каталога предлагается посмотреть маршрут
   и явно начать новую прогулку.
6. Каждые семь действительно увиденных работ образуют выставочный рубеж. Сайт
   собирает минималистичную экспозицию и название из пройденных подборок.

## Данные и приватность

`getWanderCatalogue` читает только опубликованные подборки с минимум двумя
опубликованными публикациями (правило совпадает с публичной страницей подборки).
В прогулку входят только опубликованные посты с пригодным URL первой картинки.
`showInAll` не используется: это настройка общей ленты, не приватности поста.

Клиент получает компактный каталог: ID, slug, подписи, ссылки на первую картинку
и связи с подборками. Тела постов, черновики и административные поля не передаются.
Изображения загружаются по мере показа, миниатюры маршрута — лениво. Работа
попадает в выставку только после успешной загрузки изображения. При ошибке можно
повторить загрузку или пропустить работу; пропуск не считается просмотром.

Последовательность ID, успешно загруженные работы и текущая позиция сохраняются
только в `sessionStorage`
под ключом `alice:wander:v1`. При возвращении или перезагрузке ID сверяются с
актуальным публичным каталогом. Скрытые и удалённые работы исключаются. При
запрете хранилища прогулка продолжает работать без сохранения между страницами.
База данных, аккаунты и серверное состояние сессий не нужны.

Страница имеет `noindex, follow`: индексируются исходные посты и подборки.
Изменений схемы, миграций и новых переменных окружения нет.

## Проверка

`npm test` включает проверки переходов, повторов, пустого каталога, фильтрации
публикаций, повреждённого/запрещённого хранилища, восстановления маршрута,
ошибок изображений и завершения прогулки. Анимация учитывает
`prefers-reduced-motion`; элементы доступны с клавиатуры.

Если в локальной БД нет подходящих подборок, `/wander` показывает пустое
состояние. Для наполненной прогулки нужны существующие опубликованные подборки
с двумя или более опубликованными постами и хотя бы одним изображением.
